# Lunar Lander Ballistic Descent Optimizer

Проект моделирует участок снижения лунного посадочного аппарата от схода с окололунной орбиты до высоты **2000 м**, на которой управление предполагается передать следующему контуру управления / ИИ-системе.

Код выполняет:

- аналитический расчёт импульса схода с орбиты;
- численное моделирование движения посадочного аппарата;
- оптимизацию параметров профиля снижения;
- оценку расхода топлива;
- построение графиков траектории, скоростей и массы аппарата.

---

## Описание задачи

Скрипт ищет оптимальные параметры управления посадочным аппаратом, чтобы к высоте **2000 м** получить целевые скорости:

```python
TARGET_VX = 35.0   # м/с
TARGET_VY = -35.0  # м/с
```

Оптимизация подбирает:

- высоту начала powered descent / схода с орбиты `H_pdi`;
- коэффициент П-регулятора вертикальной скорости `Kp`;
- начальную целевую вертикальную скорость `Vy_start_target`;
- конечную целевую вертикальную скорость `Vy_end`;
- степень кривизны глиссады `N`.

Целевая функция минимизирует суммарный расход топлива и штрафует отклонение вертикальной скорости от заданного значения на высоте 2000 м.

---

## Основные возможности

- Расчёт перехода с круговой орбиты высотой 100 км на эллиптическую траекторию.
- Моделирование движения в двумерной плоскости `X-Y`.
- Учёт:
  - гравитации Луны;
  - тяги двигателя;
  - расхода топлива;
  - сухой массы аппарата;
  - ограничения максимальной тяги.
- Байесовская оптимизация с помощью `scikit-optimize`.
- Визуализация:
  - профиля траектории;
  - горизонтальной и вертикальной скорости;
  - фазового портрета `Vx(X)`;
  - изменения массы аппарата.

## Динамика посадочного аппарата

Функция:

```python
lander_dynamics(t, state, Kp, Vy_start_target, Vy_end, N, H_pdi)
```

описывает движение аппарата во время активного снижения.

Вертикальная скорость задаётся профилем:

```python
vy_desired = Vy_end + (Vy_start_target - Vy_end) * (h_norm ** N)
```

где:

```python
h_norm = y / H_pdi
```

$π$-регулятор рассчитывает требуемое вертикальное ускорение:

```python
ay_desired = Kp * (vy_desired - vy)
```

Затем вычисляется вертикальная компонента тяги `Ty`, а оставшаяся доступная тяга используется для торможения по горизонтали.

---

## Логика горизонтального торможения

Код использует простое правило:

```python
if vx > TARGET_VX + 5.0:
    Tx = -Tx_max
elif vx > TARGET_VX:
    Tx = -Tx_max * ((vx - TARGET_VX) / 5.0)
else:
    Tx = 0
```

То есть:

- если горизонтальная скорость значительно выше целевой — аппарат тормозит максимально;
- если скорость близка к целевой — тяга плавно уменьшается;
- если целевая скорость достигнута — тяга по горизонтали отключается, чтобы экономить топливо и оставить тягу для вертикального управления.

## Оптимизация

Оптимизация выполняется функцией:

```python
gp_minimize(objective, space, x0=x0, n_calls=70, random_state=42)
```

Используется байесовская оптимизация по гауссовскому процессу.

Пространство поиска:

```python
space = [
    Real(0.05, 0.5, name='Kp'),
    Real(-30.0, 0.0, name='Vy_start_target'),
    Real(-60.0, -20.0, name='Vy_end'),
    Real(0.5, 2.5, name='N'),
    Real(12000.0, 25000.0, name='H_pdi')
]
```

Начальное приближение:

```python
x0 = [0.1, -10.0, -40.0, 1.0, 18000.0]
```

## Целевая функция

Функция:

```python
objective(params)
```

оценивает качество набора параметров.

Она учитывает:

1. Расход топлива на сход с орбиты.
2. Расход топлива на активное снижение.
3. Отклонение вертикальной скорости от целевой на высоте 2000 м.

Формула функции потерь:

```python
loss = total_fuel_consumed + 1000.0 * error_vy
```

Если аппарат не достигает высоты 2000 м или почти полностью расходует топливо, возвращается большой штраф:

```python
999999.0
```

## Важные замечания

- Модель является упрощённой и предназначена для расчётного моделирования / прототипирования.
- Гравитация Луны в активной фазе принята постоянной:

```python
G_MOON = 1.62
```

- Аэродинамические силы не учитываются, так как моделируется посадка на Луну.
- Управление по горизонтальной скорости реализовано эвристически.
- Управление по вертикальной скорости реализовано через П-регулятор.
- Для реальной миссии требуется более строгая модель динамики, навигации, ограничений двигателя и ориентации аппарата.
