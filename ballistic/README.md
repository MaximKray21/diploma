# Оптимизация мягкой посадки на Луну

Программа реализует вычислительную часть задачи, сформулированной в разделе
«Теоретические основы оптимизации мягкой посадки космического аппарата на Луну
по минимуму расхода топлива». Она решает задачу для фиксированного времени
посадки либо для семейства времён от 600 до 3600 секунд. Используется плоская
модель с переменной массой, свободным конечным углом и минимизацией расхода
топлива.

Численная схема — прямая множественная пристрелка с RK4 и IPOPT. Расчёт
ведётся в безразмерных переменных. Вектор управления содержит радиальную и
трансверсальную компоненты относительной тяги; ограничение его нормы
эквивалентно `0 <= delta <= 1`. Такой вариант устойчивее простой пристрелки по
четырём неизвестным начальным сопряжённым переменным. Дискретные сопряжённые
переменные восстанавливаются из множителей ККТ и используются для проверки
функции переключения и гамильтониана.

## Развёртывание окружения

Требуется Python 3.12 или новее. В корне проекта создайте отдельное виртуальное
окружение и установите зависимости:

```bash
cd /path/to/ballistic
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

В Linux при ошибке `ensurepip is not available` установите системный пакет
`python3-venv` (либо пакет `python3.<версия>-venv` для используемой версии
Python), затем повторите создание окружения.


## Запуск

```bash
cd /home/kgmsjob/ballistic
source .venv/bin/activate
python run.py --duration 1800 --nodes 80 --output results
```

Целевая высота и, при необходимости, угловая дальность посадки задаются
отдельно. По умолчанию это поверхность Луны и свободный угол:

```bash
python run.py --duration 2800 --terminal-altitude 500 \
  --terminal-beta-deg 132.7608 --output result_500m
```

Для контрольного сценария с конечной высотой 500 м предусмотрен пресет с
физическими параметрами, временем и конечной точкой:

```bash
python run.py --example-500m --nodes 160 --output example_500m
```

В контрольном сценарии сухая масса принята равной 5000 кг. Ограничение топлива
неактивно: контрольная конечная масса на высоте 500 м составляет 5554.888 кг.
Поэтому выбор сухой массы не изменяет найденный оптимум.

При 160 интервалах текущая реализация даёт 5554.983 кг на высоте 500 м при
нулевых скоростях и угле 132.7608°. Разница с контрольной массой составляет
0.095 кг; для дальнейшего сближения увеличивайте `--nodes` и сопоставляйте
времена включения двигателя с контрольными значениями 14.23074 с и 2245.256 с.

Всё семейство из 51 задачи:

```bash
python run.py --family --nodes 100 --output results_family
```

Значения массы, сухой массы, тяги и эффективной скорости истечения по
умолчанию являются демонстрационными. Их следует заменить параметрами
исследуемого аппарата:

```bash
python run.py --duration 1200 \
  --initial-mass 15000 --dry-mass 5000 \
  --thrust 60000 --exhaust-velocity 3050
```

Для каждой длительности создаются `trajectory.csv`, `report.json` и
`trajectory.png`. Общая зависимость расхода от времени записывается в
`summary.csv`.

## Проверка

```bash
python -m pytest -q
```

Если `pytest` не установлен, базовые тесты можно запустить после его установки
в `.venv`. Основная практическая проверка — повторный расчёт с большим числом
узлов (например, 80, 120 и 160) и сравнение расхода и конечных невязок.
