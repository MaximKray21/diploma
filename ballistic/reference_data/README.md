# Контрольная траектория до высоты 500 м

Файл `example_500m_trajectory.csv` содержит 58 контрольных точек траектории
спуска. Конечные условия этого набора: высота 500 м, нулевые радиальная и
трансверсальная скорости, угловая дальность 132.7608°.

Набор предназначен для проверки реализации вычислительной части раздела
«Теоретические основы оптимизации мягкой посадки космического аппарата на Луну
по минимуму расхода топлива». Единицы столбцов указаны в именах; `height_km`
и `range_km` заданы в километрах.

Строки при `time_s=14.23074` и `time_s=2245.256` повторяются намеренно: они
задают границы фаз работы двигателя. Столбец `note` поясняет сторону границы.

Скрипт `../compare_reference_trajectory.py` интерполирует рассчитанную
траекторию в эти моменты, сохраняет построчные ошибки и строит график. Пример:

```bash
python compare_reference_trajectory.py \
  --solution results_example_500m_160/T_2800_s/trajectory.csv \
  --output comparison_example_500m
```
